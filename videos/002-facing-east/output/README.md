# Facing East — deliverables

| File | What it is |
|---|---|
| `final_video.mp4` | Approved episode: 1920×1080, 30 fps, H.264 High, yuv420p, 18 Mbps, AAC 320 kbps 48 kHz stereo, 4:37 |
| `subtitles.en.srt` | English subtitles, identical to the on-screen narration |
| `music.wav` | Standalone score, 48 kHz / 16-bit stereo, −14 LUFS |
| `thumbnail_frame.png` | 1280×720 thumbnail base (the dawn reveal, 3:16) |
| `script.md` | Final script: logline, moral, scene table, palette |
| `youtube_upload.md` | Title, description, chapters, tags, pinned comment |
| `production_notes.md` | Brainstorm and scores, tools, fact sources, QA checklist |

Media files are stored with Git LFS (`git lfs install && git lfs pull`).

**Source code:** everything here is generated by `../build.py` from `../src/` and the shared toolkit in
`../../../shared/foxfolly/`. Rebuild from the episode folder with `python build.py` (see `../README.md`).
